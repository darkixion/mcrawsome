# Colour sources

The gamut primaries, white points, matrices and transfer curves in `src/mcrawsome/colour/` use each
maker's published formula and constants as printed, checked against the documents below. Page numbers
in the code and tests are the PDF's own pages (page 1 is the cover where there is one). A value marked
"recalled" is covered by none of these documents and rests on cross-checks instead: the makers'
matrices agree with their primaries, and colour-science agrees.

The documents are their makers' copyright and are not part of this repository.
